Question 1

Consider the function of x below, where z is a real constant:

f(x) = 2x + 3, if x > 0
f(x) = -2x + 5z + 4, if x < 0
f(x) = 5z, if x = 0

a - For which value of z, if any, is f continuous at x = 0?
b - For which value of z, if any, does the right-hand derivative exist at x = 0? State its value.
c - Does the left-hand derivative ever exist at x = 0? Justify using the difference quotient.
d - For which value of z, if any, does the two-sided derivative at x = 0 exist?
e - Calculate all derivatives of f that do exist, and explain each answer using limits.
